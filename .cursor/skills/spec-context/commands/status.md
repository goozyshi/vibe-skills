# /status

查看当前活跃需求状态。

## 步骤

1. 读取 `specs/index.json`。
2. 按 status 分组展示：

```
## Active
| ID | 标题 | 进度 | 更新日期 |
|----|------|------|----------|
| REQ-xxx | ... | 60% | 2026-08-14 |

## Dev-Complete（等待验收）
| ID | 标题 | SHA |
|----|------|-----|
| REQ-yyy | ... | abc1234 |
```

3. 若无活跃 spec → 输出"当前无活跃需求"。

完成标志：状态表已展示。
