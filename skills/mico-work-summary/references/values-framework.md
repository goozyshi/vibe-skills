# 价值观维度参考

撰写年终自评的价值观部分时加载此文件。选择1-2个最相关的维度，结合具体行为案例撰写。

## 四个价值观维度

### 正念 Do Right

**内涵释义**：思行正道，坚持长期主义，持续创造价值。

**行为准则**：
1. 善良、正直、利他
2. 自驱向上，持续创造价值
3. 有原则有底线，敢于对不正确的事说不
4. 看长期不投机，面对压力和诱惑也能做出正确的选择

**自评撰写指引**：
回顾全年，是否有过"短期利益 vs 长期价值"的决策场景？选择了什么？为什么？结果如何？

---

### 极端 Push Beyond

**内涵释义**：极高标准，极端拼搏，追求更高目标。

**行为准则**：
1. 全力以赴，极致交付
2. 追求更高目标而非满足现状
3. 创新敢为，冲破边界而非依赖资源
4. 敢"死磕"问题，不解决不罢休

**自评撰写指引**：
回顾全年，在哪个项目或任务上体现了"不满足于完成，追求超出预期"？具体做了什么突破常规的事？

---

### 简单 Stay Simple

**内涵释义**：以简单的方式专注于成事。

**行为准则**：
1. 理性沟通，坦诚直接，就事论事
2. 不唯上，不钻营关系
3. 有ownership，不推诿有担当
4. 做事抓本质，深究根因，把握规律

**自评撰写指引**：
回顾全年，是否有过"化繁为简"解决复杂问题的案例？是否在沟通协作中做到了坦诚直接、就事论事？

---

### 谦卑 Stay Humble

**内涵释义**：保持开放心态，持续学习，多元兼容。

**行为准则**：
1. 小ego大格局，闻过则喜，从善如流
2. 保持好奇和敏锐，持续学习，博采众长
3. 理解和欣赏多元，包容差异，有效合作
4. 深入一线掌握一手信息

**自评撰写指引**：
回顾全年，在哪些场景下接受了他人的批评或建议并做出改进？学习了哪些新知识或技能？如何与不同背景的人合作？
