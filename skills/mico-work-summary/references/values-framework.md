## 价值观体系概览

| 价值观 | 核心词 | 一句话释义 |
|-------|-------|-----------|
| **正念** Do Right | 长期主义、利他 | 思行正道，坚持长期主义，持续创造价值 |
| **极端** Push Beyond | 极致、拼搏 | 极高标准，极端拼搏，追求更高目标 |
| **简单** Stay Simple | 专注、坦诚 | 以简单的方式专注于成事 |
| **谦卑** Stay Humble | 开放、学习 | 保持开放心态，持续学习，多元兼容 |

## 四大价值观详解

### 正念 Do Right

**内涵释义**：
思行正道，坚持长期主义，持续创造价值。

**行为准则**：

1. **善良、正直、利他**
   - 关键词：用户第一、团队优先、不损人利己

2. **自驱向上，持续创造价值**
   - 关键词：主动性、结果导向、持续产出

3. **有原则有底线，敢于对不正确的事说不**
   - 关键词：坚守底线、敢于拒绝、不妥协

4. **看长期不投机，面对压力和诱惑也能做出正确的选择**
   - 关键词：长期价值、抵御诱惑、正确决策

**践行场景示例**：

**场景1：用户体验 vs 短期收入**
```markdown
情境：运营提出在核心页面增加弹窗广告，预计提升付费转化10%，但会影响用户体验。

决策：拒绝弹窗方案，改用更轻量的推荐位，虽然转化率只提升5%，但不伤害用户体验。

体现：坚持长期主义（用户体验优先），拒绝短期利益诱惑。

结果：该期间用户留存率反而提升2%，验证了长期价值导向的正确性。
```

**场景2：技术债 vs 新功能**
```markdown
情境：项目排期紧张，可以选择快速上线新功能（但会留下技术债），或者花时间重构后再上线。

决策：说服产品延期1周，先重构底层架构再上线新功能。

体现：有原则有底线，不为短期压力牺牲长期质量。

结果：虽然上线延期，但后续迭代速度提升30%，避免了更大的返工成本。
```

### 极端 Push Beyond

**内涵释义**：
极高标准，极端拼搏，追求更高目标。

**行为准则**：

1. **全力以赴，极致交付**
   - 关键词：全力以赴、超出预期、极致品质

2. **追求更高目标而非满足现状**
   - 关键词：不满足、持续挑战、更高标准

3. **创新敢为，冲破边界而非依赖资源**
   - 关键词：突破限制、创新方法、不找借口

4. **敢"死磕"问题，不解决不罢休**
   - 关键词：坚韧不拔、钻研精神、攻坚克难

**践行场景示例**：

**场景1：性能优化的极致追求**
```markdown
情境：页面加载时间从3s优化到1.5s后，团队认为已经达标可以收工。

决策：不满足现状，继续深挖性能瓶颈，最终优化到0.5s。

体现：追求更高目标而非满足现状，全力以赴追求极致交付。

结果：用户留存率因加载速度提升额外增长5%，超出预期。
```

**场景2：资源有限下的突破**
```markdown
情境：新功能开发需要3个月，但只给了1.5个月时间，且人力不足。

决策：不依赖资源，通过技术创新（复用底层能力、自动化工具）突破限制。

体现：冲破边界而非依赖资源，创新敢为。

结果：按时高质量交付，并沉淀了一套可复用的开发框架，后续项目效率提升40%。
```

### 简单 Stay Simple

**内涵释义**：
以简单的方式专注于成事。

**行为准则**：

1. **理性沟通，坦诚直接，就事论事**
   - 关键词：直接反馈、不绕弯子、基于事实

2. **不唯上，不钻营关系**
   - 关键词：独立思考、不拍马屁、不搞关系

3. **有ownership，不推诿有担当**
   - 关键词：主人翁、不甩锅、主动担责

4. **做事抓本质，深究根因，把握规律**
   - 关键词：透过现象看本质、根因分析、抓重点

**践行场景示例**：

**场景1：直接反馈技术方案问题**
```markdown
情境：技术评审会上，发现架构师提出的方案有明显缺陷，但其他人碍于职级都未提出质疑。

决策：会上直接指出问题："这个方案在XX场景下会有性能瓶颈，建议改为YY方案。"

体现：理性沟通，坦诚直接，就事论事。不唯上，不因为对方职级高就沉默。

结果：架构师认可反馈，采纳建议，避免了后续的性能灾难。
```

**场景2：担责而非推诿**
```markdown
情境：线上故障，是因为上游服务调用超时导致，可以归咎于上游团队。

决策：主动担责，承认自己服务的容错机制不足，没有做好降级方案。

体现：有ownership，不推诿有担当。抓本质（根因是容错不足，而非单纯上游问题）。

结果：推动建立了全链路容错机制，类似问题再未发生。
```

### 谦卑 Stay Humble

**内涵释义**：
保持开放心态，持续学习，多元兼容。

**行为准则**：

1. **小ego大格局，闻过则喜，从善如流**
   - 关键词：接受批评、虚心改进、格局大

2. **保持好奇和敏锐，持续学习，博采众长**
   - 关键词：好奇心、终身学习、学习他人

3. **理解和欣赏多元，包容差异，有效合作**
   - 关键词：包容、多元、跨团队协作

4. **深入一线掌握一手信息**
   - 关键词：接地气、一线调研、不坐办公室

**践行场景示例**：

**场景1：接受新人质疑**
```markdown
情境：应届生在代码review中指出我的代码有更优写法。

决策：立即采纳建议，并在团队内分享这个优化方法。

体现：小ego大格局，闻过则喜，从善如流。博采众长（向新人学习）。

结果：团队形成了良好的代码review文化，整体代码质量提升。
```

**场景2：深入一线发现真实问题**
```markdown
情境：数据显示某功能留存率低，但原因不明。

决策：不依赖二手报告，亲自访谈20位流失用户，录屏观察真实使用场景。

体现：深入一线掌握一手信息，不依赖间接数据。

结果：发现核心问题是新手引导不清晰（而非功能本身），针对性优化后留存率提升15%。
```

## 价值观撰写指南

### 基本原则

1. **必须结合具体案例**
   - ❌ "我始终践行正念价值观"（空泛表态）
   - ✅ "在XX场景下，我选择了XX，因为..."（具体案例）

2. **聚焦1-2个最相关的价值观**
   - 不要面面俱到地罗列所有价值观
   - 选择本年度工作中体现最明显的1-2个深入展开

3. **说明价值观如何影响了决策**
   - 不只是描述行为，要说明为什么这个行为体现了价值观
   - 展示价值观在关键时刻如何指导选择

### 撰写结构模板

```markdown
## 价值观：[选择1-2个]

### [价值观名称]

**案例：[具体事件标题]**

**情境**：
- 当时面临的决策或挑战
- 有哪些选择？各有什么代价？

**决策过程**：
- 如何权衡？哪些因素影响了决策？
- 价值观在其中起了什么作用？

**最终选择**：
- 做了什么决定？为什么这个选择体现了该价值观？

**结果**：
- 短期：可能有哪些代价？
- 长期：带来了什么价值？
```

### 常见误区

**误区1：泛泛而谈**
```markdown
❌ "本年度我始终坚持正念价值观，在工作中保持长期主义思维。"
✅ "Q2面对短期收入压力，我拒绝了损害用户体验的弹窗广告方案，坚持长期价值优先。"
```

**误区2：堆砌所有价值观**
```markdown
❌ 罗列正念、极端、简单、谦卑各一个案例，每个都很简略。
✅ 深入展开1-2个最能体现个人特质的价值观，每个都有完整案例支撑。
```

**误区3：只说结果不说过程**
```markdown
❌ "我践行了极端价值观,最终超额完成目标。"
✅ "面对看似不可能的目标，我没有降低标准，而是通过XX创新方法突破限制..."
```

### 选择建议

**如何选择要写哪个价值观？**

1. **回顾全年关键决策**：哪些决策时刻让你印象深刻？
2. **识别核心冲突**：是否有短期vs长期、完成vs极致、复杂vs简单的权衡？
3. **匹配价值观**：这些决策体现了哪个价值观？
4. **选择最突出的1-2个**：不求全面，求深度

**四个价值观的典型场景**：

| 价值观 | 典型冲突场景 | 践行表现 |
|-------|-----------|---------|
| 正念 | 短期利益 vs 长期价值 | 拒绝投机，坚持对的事 |
| 极端 | 完成任务 vs 追求极致 | 不满足现状，突破边界 |
| 简单 | 复杂流程 vs 高效决策 | 化繁为简，直接有效 |
| 谦卑 | 坚持己见 vs 接纳意见 | 虚心学习，开放协作 |
