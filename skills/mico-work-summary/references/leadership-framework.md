## 管理维度概览

| 维度 | 核心关注 | 一句话释义 |
|-----|---------|-----------|
| **管好业务** | 目标达成、策略有效性 | 制定明确目标和清晰策略，带领团队解决问题并实现目标 |
| **带好团队** | 人才培养、团队氛围 | 组建高效团队，识别优劣势，帮助成员发挥潜力 |
| **传好文化** | 价值观践行、文化传递 | 以身作则传递价值观，营造向上奋进的工作环境 |

## 三大管理维度详解

### 管好业务

**释义**：
制定明确的团队目标和清晰的策略，通过有效的高质量的过程管理，带领团队解决问题挑战并实现目标。在公司层面通过加强前后端协同作战，取得突破。同时敏锐的发现和把握业务机会，不断实现超越。

#### 评估维度

**1. 目标设定与达成**
- 团队目标是否明确、合理、可衡量？
- 年度目标达成情况如何？关键指标完成率？
- 未达成的部分原因是什么？

**2. 策略制定与调整**
- 是否制定了清晰的策略和路径？
- 面对变化时是否及时调整策略？
- 策略是否得到团队理解和执行？

**3. 过程管理质量**
- 重点项目的推进节奏如何？有无明显延期？
- 是否建立了有效的风险识别和应对机制？
- 资源分配（人力、时间）是否合理？

**4. 协同作战能力**
- 与其他团队（产品、运营、前端/后端）的协作效率如何？
- 是否主动推动跨团队协同，打破部门墙？

**5. 业务敏锐度**
- 是否主动发现和把握业务机会？
- 对行业趋势和竞品动态的敏感度如何？

#### 自评模板

```markdown
## 管好业务

### 1. 业务目标达成

**年度目标**：
- [目标1]：预期XX，实际达成YY（完成率Z%）
- [目标2]：预期AA，实际达成BB（完成率C%）

**整体评估**：
- 超出预期的部分：[哪些目标超额完成？为什么？]
- 未达成的部分：[哪些目标未完成？主要原因？]

### 2. 策略制定与执行

**核心策略**：
- [策略1]：为什么制定这个策略？效果如何？
- [策略2]：中途是否调整？调整的依据是什么？

**策略有效性**：
- 哪些策略证明有效？可复用的经验是什么？
- 哪些策略效果不佳？如果重来会怎么调整？

### 3. 过程管理

**重点项目复盘**：

项目A：[做得好的项目]
- 管理亮点：[在项目管理上有哪些有效举措？]
- 可复用经验：[这个项目的管理经验可以推广到其他项目吗？]

项目B：[有问题的项目]
- 管理不足：[过程中哪里出了问题？]
- 改进方向：[如果重来会怎么做？]

**资源调度**：
- 人力分配是否合理？有无资源浪费或明显瓶颈？
- 是否及时识别风险并调整资源？

### 4. 协同作战

**跨团队协作**：
- 与XX团队（产品/运营/其他技术团队）的协作效率如何？
- 是否主动推动协同，解决跨团队问题？

**具体案例**：
- [某次跨团队协作的成功案例或失败教训]

### 5. 业务敏锐度

**机会把握**：
- 本年度是否主动发现并推动了新的业务机会？
- [具体案例：如何发现机会？如何推动落地？]

**行业洞察**：
- 对行业趋势的判断是否准确？
- 是否关注竞品动态并及时调整策略？
```

#### 示例

```markdown
## 管好业务

### 1. 业务目标达成

**年度目标**：
- 商业化收入：预期增长50%，实际增长85%（完成率170%）
- 用户留存率：预期提升到60%，实际达到58%（完成率97%）

**整体评估**：
- 超出预期：商业化收入通过Q3上线的会员体系超额完成，会员付费转化率达到8%，远超预期的5%
- 未完全达成：留存率因Q2竞品冲击影响了新用户增长，虽然Q3-Q4及时调整策略，但全年未完全达标

### 2. 策略制定与执行

**核心策略**：
全年采用"三阶段递进"策略：
- Q1-Q2：基础能力建设（礼物体系、支付链路）
- Q2-Q3：转化漏斗优化（降低付费门槛、优化引导）
- Q3-Q4：分层运营（会员体系、差异化权益）

**策略有效性**：
- Q3及时调整：原计划Q3继续优化转化漏斗，但数据显示付费用户已接近天花板，果断调整为上线会员体系，开辟新的收入增长点
- 这次调整验证了"基于数据快速决策"的有效性，后续会保持这种敏捷策略调整能力

### 3. 过程管理

**项目A：会员体系上线（做得好）**

管理亮点：
- 提前识别风险：Q2评估时发现技术债会影响Q3上线，果断安排1个月重构
- 双周同步机制：与产品/运营建立双周对齐会，及时解决争议，避免临近上线才发现分歧
- 灰度验证：5% → 20% → 50%三轮灰度，每轮观察1周数据再决策，稳健推进

结果：按时高质量上线，上线后无重大故障，会员付费转化率达到8%

**项目B：留存优化（有问题）**

管理不足：
- 前期调研不充分：Q1-Q2聚焦优化产品功能，但未深入调研流失原因，方向偏了
- 数据反馈滞后：缺少实时监控，Q2结束才发现留存率未改善，浪费了2个月

改进方向：
- 后续重点项目启动前必须做为期2周的用户调研和数据分析，明确根因后再动手
- 建立周度数据监控，及时发现问题

### 4. 协同作战

**与产品团队协作**：
- Q2因需求优先级产生分歧，我主动组织了联合workshop，用数据说服产品调整优先级，最终达成共识
- 建立了产研周会机制，提前暴露问题，协作效率提升30%

**与运营团队协作**：
- Q3会员体系上线时，技术和运营首次深度协作，从功能设计到定价策略全程参与
- 这次协作打破了"技术只做实现"的惯性，让技术侧更理解业务

### 5. 业务敏锐度

**机会把握**：
Q2数据分析时发现高价值用户（月消费>1000元）占比虽小（8%）但贡献了60%收入，敏锐意识到这是做会员体系的机会。主动推动立项，Q3上线后会员用户占比提升到15%，成为核心收入增长点。

**行业洞察**：
关注到竞品Q2密集推出社交互动功能，及时调整roadmap，将PK连麦功能提前到Q3上线，避免被竞品拉开差距。
```

### 带好团队

**释义**：
通过外引内培组建和培养高效的团队，识别队员的优劣势，有效地管理队员，合理分配资源，奖优汰劣。建立良好的团队氛围和协作基础，帮助队员发挥最大潜力,加速成长。

#### 评估维度

**1. 团队组建与人才梯队**
- 团队结构是否合理？是否有明显短板？
- 外部招聘和内部培养的效果如何？
- 是否建立了人才梯队？关键岗位有无backup？

**2. 成员成长**
- 团队成员能力提升情况如何？有多少人晋升或能力明显提升？
- 采取了哪些培养措施？1v1、导师制、项目历练？
- 哪些成员成长超出预期？哪些成长不及预期？

**3. 优劣势识别与管理**
- 是否清楚每个成员的优势和短板？
- 是否做到了"人尽其才"（安排合适的人做合适的事）？
- 对表现不佳的成员如何处理？

**4. 团队氛围**
- 团队协作效率如何？有无明显矛盾或摩擦？
- 团队士气如何？主动性强不强？
- 离职率如何？核心人才是否稳定？

**5. 激励与淘汰**
- 是否建立了有效的激励机制？
- 对高绩效成员是否给予足够认可和回报？
- 对低绩效成员是否及时反馈和调整？

#### 自评模板

```markdown
## 带好团队

### 1. 团队组建

**团队现状**：
- 团队规模：[人数、结构]
- 外部引入：本年度招聘X人，[关键岗位补齐情况]
- 内部培养：提拔X人到关键岗位

**人才梯队**：
- 是否建立了梯队？关键岗位是否有backup？
- 还有哪些结构性短板？

### 2. 成员成长

**成长亮点**：
- [成员A]：从XX水平成长到YY水平，具体体现在...
- [成员B]：本年度获得晋升，成长路径是...

**培养措施**：
- [措施1]：如1v1辅导、项目历练、导师制等
- [措施2]：效果如何？

**成长不及预期**：
- [成员C]：期望达到XX，实际是YY
- 原因分析：是培养方式不对？还是个人主观因素？
- 后续计划：[如何改进？]

### 3. 人才管理

**优势发挥**：
- [成员D]：擅长XX，安排其负责YY项目，效果很好
- 是否做到了"人尽其才"？

**短板管理**：
- [成员E]：在XX方面有短板，如何帮助其改进？
- 对明显不适合的成员如何处理？

### 4. 团队氛围

**协作效率**：
- 团队内部协作是否顺畅？有无明显摩擦？
- [具体案例：某次协作问题如何解决？]

**团队士气**：
- 团队主动性如何？遇到困难时的态度？
- 离职率：本年度X人离职，核心人才是否稳定？

**氛围建设**：
- 采取了哪些措施营造良好氛围？效果如何？

### 5. 激励与反馈

**高绩效激励**：
- 对表现优秀的成员给予了哪些认可和回报？
- [具体案例]

**低绩效管理**：
- 对表现不佳的成员如何反馈和调整？
- 是否及时采取行动（辅导、调岗、淘汰）？
```

#### 示例

```markdown
## 带好团队

### 1. 团队组建

**团队现状**：
- 团队规模：从年初8人扩充到12人
- 外部引入：招聘2名高级工程师（填补会员体系和数据分析短板）、2名应届生
- 内部培养：提拔1名工程师到TL岗位，带3人小组

**人才梯队**：
- 已初步建立梯队：高级工程师3人、中级4人、初级5人
- 还有短板：缺少数据分析专家，目前依赖运营团队支持

### 2. 成员成长

**成长亮点**：
- 成员A（中级→高级）：年初只能独立完成需求开发，年底已能主导复杂项目设计。Q3会员体系项目中担任技术负责人，从架构设计到上线运维全程把控，表现优秀。
- 成员B（应届生）：半年内快速成长，能独立负责中等复杂度需求，代码质量稳定在团队平均水平以上。

**培养措施**：
- 项目历练：有意识地安排成长型成员担任项目核心角色，给压力也给支持
- 双周1v1：与每个成员保持双周1v1，及时发现问题和困惑
- 代码review：坚持代码review机制，在review中传递技术标准和思路

**成长不及预期**：
- 成员C：期望能独立负责项目，但实际仍需较多指导
- 原因：技术理解力不错，但缺乏全局视角，容易陷入细节
- 后续计划：Q1安排其参与架构设计讨论,培养全局思维

### 3. 人才管理

**优势发挥**：
- 成员D擅长性能优化，安排其负责Q2留存优化中的加载速度提升，发挥了特长
- 成员E沟通能力强，安排其作为技术接口人对接产品运营，效果很好

**短板管理**：
- 成员F代码质量不稳定，多次出现线上bug
- 采取措施：安排高级工程师结对编程2周，强化代码review，Q4有改善

### 4. 团队氛围

**协作效率**：
- Q2因会员体系项目排期紧张，成员间出现过摩擦（A认为B不配合）
- 处理方式：组织团队复盘会，让双方说出困难，调整分工后问题解决

**团队士气**：
- 整体士气良好，遇到困难时大家愿意主动加班攻坚
- 离职率：全年1人离职（家庭原因），核心人才稳定

**氛围建设**：
- 双周技术分享会：鼓励成员分享技术心得，提升学习氛围
- 季度team building：Q2、Q4各组织一次，增强团队凝聚力

### 5. 激励与反馈

**高绩效激励**：
- 成员A晋升高级工程师，并在年终绩效中给予S评级
- Q3会员体系上线后，在全员会上公开表扬核心贡献者

**低绩效管理**：
- 成员G连续两个季度绩效不达标，Q3进行了明确反馈和PIP
- Q4观察期内仍无改善,最终协商离职
```

### 传好文化

**释义**：
以身作则，塑造和传递价值观和文化，建立良好的沟通渠道，营造向上奋进的工作环境，同时塑造标杆榜样，不断引导团队践行正确的价值观。

#### 评估维度

**1. 以身作则**
- 自己的言行是否一致地体现了价值观？
- 在关键时刻是否用行动展示了价值观？
- 团队成员是否认可你在文化上的表率作用？

**2. 价值观传递**
- 团队成员是否理解和认同公司价值观？
- 团队在具体工作中是否体现了价值观？
- 有没有价值观相关的冲突或偏差？如何处理？

**3. 文化塑造**
- 团队形成了什么样的文化氛围？（如开放、拼搏、创新等）
- 这种文化是否与公司文化一致？
- 新人是否能快速融入团队文化？

**4. 沟通渠道**
- 是否建立了畅通的沟通机制？（如1v1、团队会、匿名反馈）
- 团队成员是否敢于表达真实想法？
- 对团队反馈的问题是否及时回应和处理？

**5. 标杆树立**
- 团队中是否有践行价值观的标杆榜样？
- 如何树立和传播这些榜样？
- 榜样是否起到了带动作用？

#### 自评模板

```markdown
## 传好文化

### 1. 以身作则

**自我反思**：
- 在哪些关键时刻用行动展示了价值观？
- [具体案例：如何以身作则？]
- 有没有因为业务压力而在文化上妥协？

### 2. 价值观传递

**团队践行情况**：
团队在 [某价值观] 上的表现：
- 正面案例：[团队成员做了什么体现价值观的事？]
- 待改进：[哪些方面还不够？]

**价值观冲突处理**：
- [某次价值观相关的冲突或偏差]
- 如何处理？团队是否理解和接受？

### 3. 文化塑造

**团队文化特点**：
- 当前团队形成了什么样的文化氛围？
- [如开放透明、极致追求、快速迭代等]
- 这种文化是如何形成的？

**文化一致性**：
- 团队文化是否与公司文化一致？
- 新人融入速度如何？

### 4. 沟通渠道

**沟通机制**：
- 建立了哪些沟通机制？（如双周1v1、月度团队会、匿名反馈箱）
- 这些机制是否有效？团队反馈如何？

**开放度**：
- 团队成员是否敢于表达真实想法？
- 对负面反馈如何处理？

### 5. 标杆树立

**榜样案例**：
- [成员X]：在XX事件中体现了YY价值观
- 如何传播这个榜样？（如团队分享、公开表扬）
- 榜样是否起到了带动作用？

**不足之处**：
- 在文化传递上还有哪些不足？
- 后续如何改进？
```

#### 示例

```markdown
## 传好文化

### 1. 以身作则

**关键时刻案例**：
Q2项目排期紧张，团队连续加班。我没有要求大家加班，而是自己每天最晚离开，用行动告诉团队"Leader在陪你们一起战斗"。同时坚持不降低代码质量标准，拒绝"赶进度就可以写差代码"的妥协。

**自我反思**：
Q3因业务压力，曾考虑过在用户体验上妥协（上线可能影响体验的功能以换取短期收入）。最终坚持了长期主义，拒绝了这个方案。这次选择让团队看到了"正念"不是口号，是在压力下的真实选择。

### 2. 价值观传递

**团队在"极端"价值观上的表现**：

### 3. 文化塑造
```

## 管理自评撰写指南

### 基本原则

1. **真实反映管理有效性**
   - 不只说团队成绩（那是年度总结的内容）
   - 聚焦管理动作：如何决策、如何带人、如何传递文化

2. **展示管理思考深度**
   - 不只说做了什么，要说为什么这么做
   - 分析哪些管理动作有效、哪些无效
   - 说明从中学到了什么

3. **正视管理不足**
   - 管理没有完美，坦诚展示不足
   - 深挖不足背后的原因（是能力短板？还是意识不足？）
   - 说明后续如何改进

### 撰写顺序建议

1. **先写"管好业务"**
   - 这部分最客观，有数据支撑
   - 为后面两个维度提供业务背景

2. **再写"带好团队"**
   - 结合具体成员案例，更容易写得生动
   - 展示对团队的了解深度

3. **最后写"传好文化"**
   - 这部分最抽象，需要结合前两部分的案例
   - 展示价值观如何在业务和团队管理中落地

### 常见误区

**误区1：只说成绩不说管理**
```markdown
❌ "团队全年完成15个项目，收入增长80%。"（这是业务成果，不是管理评估）
✅ "通过建立双周同步机制，项目延期率从30%降到10%，提升了过程管理质量。"
```

**误区2：回避问题和不足**
```markdown
❌ "管理工作一切顺利，团队表现优秀。"（不真实，缺乏反思）
✅ "Q2项目延期暴露了资源调度问题，我对项目风险识别不够及时。后续建立了周度风险review机制。"
```

**误区3：价值观部分空泛**
```markdown
❌ "团队始终践行公司价值观。"（无效表态）
✅ "Q3成员A在XX事件中体现了'极端'价值观，我在团队会上表扬并分享案例，带动了团队氛围。"
```

**误区4：缺少具体案例**
```markdown
❌ "注重团队成长，建立了培养机制。"（抽象）
✅ "对成员B采用'项目历练+双周1v1'培养模式，半年内从中级成长到高级，能独立主导项目。"
```

### 字数建议

- 管好业务：800-1200字（可详细展开业务复盘）
- 带好团队：600-1000字（结合具体成员案例）
- 传好文化：400-800字（结合价值观案例）
- 总计：1800-3000字

- [ ] 是否展示了管理思考深度？

**价值观一致性**：
