## Install

Pick a skill and install it via the [Skills CLI](https://skills.sh/):

```bash
npx skills add goozyshi/vibe-skills@<skill-name>
```

> [!NOTE]
> Skills are plain Markdown files installed into `.cursor/skills/`. No code execution, no network calls, no config changes. Uninstall by deleting the skill folder.
